## 更新详情

v0.1.1 聚焦界面多语言与鼠标交互，同时改善了窄终端和 RTL 排版。

### 14 种界面语言

| 语言 | 代码 | 语言 | 代码 |
| --- | --- | --- | --- |
| English | `en` | Português (Brasil) | `pt-BR` |
| Español | `es` | Português (Portugal) | `pt-PT` |
| Français | `fr` | Русский | `ru` |
| Deutsch | `de` | 한국어 | `ko` |
| 简体中文 | `zh-Hans` | Türkçe | `tr` |
| 繁體中文 | `zh-Hant` | Tiếng Việt | `vi` |
| 日本語 | `ja` | العربية | `ar` |

- 首次启动自动检测系统区域设置；`settings.language` 为空时跟随系统。
- 可在 `Settings → Language` 中切换，也可用 `mclauncher --lang zh-Hans` 临时指定。
- `pt-PT` 缺失条目自动回退到 `pt-BR`，再回退到英文。
- 翻译覆盖导航、列表、设置、弹窗、页脚提示、任务阶段和常见错误；技术日志保持英文便于排查。
- 新增语言选择器，支持键盘、滚轮和鼠标操作。

### 鼠标操作

- 侧栏、版本筛选标签、底栏快捷键和弹窗按钮：单击立即生效。
- 列表行：第一次单击选中，450 ms 内再次单击才会打开、启动或编辑，避免误触。
- 滚轮：滚动实例、版本、账户、设置、控制台、帮助和选择器列表。
- 单击弹窗外部可关闭弹窗（进度弹窗除外）；表单字段可直接单击聚焦。
- 所有键盘操作保持不变，鼠标只是补充。

### 排版与本地化

- 中日韩文本按终端显示宽度排版，窄终端不再截断半个字符。
- 阿拉伯语镜像侧栏、页头、底栏、表格列和设置行，并同步反转提示顺序与进度方向。
- 设置页标签宽度动态计算，长标签不再挤压取值；描述文本自动换行。
- 窄屏下的快捷提示按整条隐藏，不再出现半截提示。
- 修正西班牙语、法语、巴西葡萄牙语和欧洲葡萄牙语中的运行时、检测提示等措辞。
- 项目名称统一为 MCLauncher TUI。

### 平台与稳定性

- Windows 控制台自动切换到 UTF-8 代码页，确保中文、日文、阿拉伯文正常显示。
- 新增 14 种语言 × 11 个界面的全屏幕预览测试，以及窄屏和鼠标交互测试。
- 语言目录测试会校验条目完整性和格式化占位符一致性。

### 升级说明

直接替换旧版可执行文件即可；配置格式兼容。升级后默认跟随系统语言，可在设置中固定语言。

### 安装

从下方 Assets 下载对应平台的压缩包：

- Windows：`mclauncher_0.1.1_windows_amd64.zip` / `mclauncher_0.1.1_windows_arm64.zip`
- Linux：`mclauncher_0.1.1_linux_amd64.tar.gz` / `mclauncher_0.1.1_linux_arm64.tar.gz`
- macOS：`mclauncher_0.1.1_darwin_amd64.tar.gz` / `mclauncher_0.1.1_darwin_arm64.tar.gz`

校验和见 `checksums.txt`。macOS 首次运行如被系统拦截：

```bash
xattr -d com.apple.quarantine ./mclauncher
```
