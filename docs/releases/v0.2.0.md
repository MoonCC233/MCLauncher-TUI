## 更新详情

v0.2.0 带来 Microsoft 正版登录、首页像素字标志、分辨率预设、版本分类和便携数据目录，是启动器第一次可以完整使用正版账户启动游戏。

### Microsoft 正版登录

- 新增 Microsoft device code 登录：在 `Accounts` 按 `a`，选择 `Sign in with Microsoft`，启动器会显示验证链接和一次性代码。
- 登录弹窗支持按 `c` 复制代码、按 `o` 打开验证页面、按 `r` 重新申请，并显示代码剩余有效期。
- 完整走通 Microsoft OAuth → Xbox Live → XSTS → Minecraft 登录流程，自动获取 Minecraft 档案、UUID 与 XUID。
- 默认使用内置公开客户端 `00000000402b5328`，无需注册 Azure 应用；也可以在设置中填写自己的 Entra 应用（客户端）ID。
- 支持保存多个 Microsoft 账户，账户列表会显示正版徽章和会话有效期；启动前会自动刷新临近过期的令牌。
- 针对没有 Xbox 档案、Xbox Live 地区不可用、儿童账户、封禁等常见错误给出具体提示。
- 启动参数现在会传入真实的 `auth_access_token`、`user_type=msa` 与 `auth_xuid`，旧版参数格式同样支持 `${auth_xuid}`。

### 首页与视觉

- 首页标志由 “MC” 改为五线像素字 “MCLAUNCHER”，全部使用大写字母，并加入自适应字距与逐行渐变着色。
- 窗口宽度不足时自动回退为单行渐变文字，避免撑破窄终端。
- 账户页新增 Microsoft 账户徽章；版本页的筛选标签在窄屏下自动换行。
- 愚人节版本使用紫色 `April Fools` 标签，与正式版、快照和远古版区分。

### 分辨率预设

- 设置页的窗口尺寸改为选择器，提供常用预设：
  - 854×480（SD）
  - 1280×720（HD）
  - 1366×768（WXGA）
  - 1600×900（HD+）
  - 1920×1080（Full HD）
  - 2560×1440（QHD）
  - 3840×2160（4K UHD）
- 保留 `Custom…` 入口，可继续手动输入任意 `宽x高`；键盘、鼠标和滚轮均可操作。

### 版本分类

- 版本页新增“远古版”和“愚人节版”筛选，按 `t` 在全部、正式版、快照、远古版、愚人节版之间循环。
- 远古版包含 Mojang 清单中的 `old_beta` 与 `old_alpha`。
- 愚人节版按已知版本白名单识别：`2.0`、`15w14a`、`1.RV-Pre1`、`3D Shareware v1.34`、`20w14infinite`、`22w13oneblockatatime`、`23w13a_or_b`、`24w14potato`、`25w14craftmine`。
- 正式版和快照分类会自动排除愚人节版本，避免它们混入普通版本列表。

### 便携数据目录

- 默认数据目录改为启动器当前工作目录下的 `.minecraft`，不再写入 `%APPDATA%` 或用户主目录。
- 新增 `Settings → Data directory`，可把游戏数据改到任意路径；切换后立即重新扫描已安装版本，无需重启。
- 配置文件固定保存在启动根目录的 `.minecraft/config.json`；修改游戏数据目录不会让启动器丢失账户和实例设置。
- `--data-dir <path>` 与 `MCLAUNCHER_DATA_DIR` 继续可用，并优先于设置中的自定义路径。
- 旧版数据不会自动迁移；升级方式见下方“升级说明”。

### 其他改进

- 设置页新增 Microsoft 客户端 ID 输入项。
- 新增 `account-type`、`microsoft`、`microsoft-error`、`resolution` 四个预览屏，方便生成文档截图。
- 14 种界面语言补齐 31 个新条目，新增文案均通过占位符与完整性测试。
- 修复鼠标点击区域与画面错位：弹窗在居中余量为奇数时整体偏移 1 格、窄屏顶部导航点击区逐项右移、空实例页提示行点击区下移 1 行；被裁剪的行和按钮也不再响应点击。
- 新增 Microsoft 登录、配置账户增改、启动参数、版本分类、分辨率选择、数据目录切换、标志回退和点击命中区域的单元测试。
- README 补充正版登录、便携目录、分辨率预设和版本分类说明。

### 平台与兼容性

- Windows、Linux、macOS 的 amd64 / arm64 构建目标保持不变。
- 配置格式向后兼容；新增字段均有空值处理，旧配置可以直接读取。
- Microsoft 登录需要网络和浏览器；部分账户首次使用前可能需要在 `xbox.com` 创建 Xbox 档案。
- 自定义 Entra 应用需要获得 Mojang 审批，否则 `api.minecraftservices.com` 可能返回 403；内置客户端不受此限制。
- Microsoft 登录令牌以明文 JSON 保存在 `config.json`，请勿分享该文件。

### 升级说明

v0.2.0 的默认数据目录已改为当前目录的 `.minecraft`。如果希望继续使用旧版本的数据：

1. 用旧数据目录启动：`mclauncher --data-dir "<旧数据目录>"`，或设置环境变量 `MCLAUNCHER_DATA_DIR`。这样会直接读取旧目录中的 `config.json`、版本、实例和存档。
2. 也可以把旧 `config.json` 复制到新的 `.minecraft`，再在 `Settings → Data directory` 中指向旧目录，复用已有的版本与存档。

旧版 `%APPDATA%\mclauncher` 等目录不会被自动删除或迁移。

### 安装

从下方 Assets 下载对应平台的压缩包：

- Windows：`mclauncher_0.2.0_windows_amd64.zip` / `mclauncher_0.2.0_windows_arm64.zip`
- Linux：`mclauncher_0.2.0_linux_amd64.tar.gz` / `mclauncher_0.2.0_linux_arm64.tar.gz`
- macOS：`mclauncher_0.2.0_darwin_amd64.tar.gz` / `mclauncher_0.2.0_darwin_arm64.tar.gz`

校验和见 `checksums.txt`。macOS 首次运行如被系统拦截：

```bash
xattr -d com.apple.quarantine ./mclauncher
```
