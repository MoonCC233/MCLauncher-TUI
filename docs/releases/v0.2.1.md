## 更新详情

v0.2.1 带来可自定义的主题系统、后台任务与 `Downloads` 页面、已安装版本卸载，以及版本页标题右侧的即时搜索框。搜索框会跟随当前主题与强调色，并完整支持窄屏、中文/日文/韩文宽字符和阿拉伯语 RTL 布局。

### 版本搜索

- 版本页的搜索框移到“版本”标题右侧，随窗口宽度自动伸缩，替代原来的 `/` 筛选状态行。
- 输入版本 ID 即可即时过滤列表；按 `/` 聚焦搜索框，按 `esc` 清除搜索，再按一次返回首页。
- 搜索框可直接用鼠标单击聚焦，点击其他区域会退出搜索；底栏快捷键同步改为“搜索”。
- 窗口变窄时优先隐藏右侧的清单来源与版本数量，保证搜索框仍有可用宽度；标题行只显示清单总数，输入时不会因元数据宽度变化而跳动。
- 14 种界面语言都补齐了“搜索”和“搜索版本”文案；搜索框背景、提示符、光标和清除提示均使用当前主题颜色。

### 主题与强调色

- 设置页新增主题选择器，内置 OpenCode、Midnight、Forest、Rose、Mono 五种配色。
- 支持输入任意十六进制强调色，立即应用到侧栏、标题、按钮、进度条、版本标签和搜索框等界面元素。
- 选择 `Custom accent…` 可自定义强调色，`Reset accent` 恢复主题默认值；主题与强调色都会写入配置，下次启动继续生效。
- 新增颜色解析与主题切换测试，非法主题 ID 和颜色会安全回退到默认值。

### 后台任务与 Downloads

- 安装和游戏启动可以留在后台继续执行：进度弹窗中按 `b` 转入后台，按 `d` 直接打开 `Downloads`。
- 新增 `Downloads` 页面，可查看当前任务进度、阶段、文件数量与传输速度；按 `enter` 重开进度弹窗，按 `x` 取消当前任务。
- 最近 20 条完成、失败或取消的任务会保留在当前会话的历史记录中，可用 `↑` / `↓`、`pgup` / `pgdown`、`home` / `end` 和鼠标滚轮翻看。
- 后台启动完成时不会打断当前页面、弹窗或控制台视图；成功和失败的启动也会记录到历史中。
- 安装任务只有在实例保存成功后才标记为完成；保存失败会回滚内存中的实例并显示为失败。
- 任务在最后一个阶段之后被取消时，不会再启动游戏。

### 已安装版本卸载

- 版本页按 `d` 可卸载已安装版本，删除前会显示确认弹窗；未安装的版本会提示先安装。
- 游戏正在运行或同一版本仍有安装任务时，会阻止卸载并给出提示。
- 卸载时先把版本目录移动到临时位置，再执行删除，避免删除失败留下半损坏的版本目录；使用该版本的实例会在下次启动时重新安装。
- 新增卸载流程与安全删除测试。

### 修复与改进

- 旧版 XML 日志配置会在启动游戏前改写为控制台可读的 `PatternLayout`，避免控制台出现整行 XML；安装进度回调增加空值保护。
- 版本元数据中的启动参数现在可以正确序列化和回读，兼容旧版 `Rules` / `Values` 字段，参数中包含空格或 `=` 时也能保持原样。
- 14 种界面语言补齐主题、Downloads、卸载和任务状态相关文案，并新增翻译完整性测试。
- 修复后台任务、取消、卸载和 Downloads 流程中的边界问题，包括后台启动抢占界面、实例保存失败仍显示完成、下载历史无法滚动等。
- 新增主题、后台任务、下载历史、卸载、参数序列化和版本搜索框的单元测试；README 与版本页截图同步更新。

### 平台与兼容性

- Windows、Linux、macOS 的 amd64 / arm64 构建目标保持不变。
- 配置格式向后兼容：新增 `theme` 与 `theme_accent` 字段均可缺省，旧配置可以直接读取。
- 主题与搜索框使用终端真彩色；不支持真彩色的终端会按终端能力近似显示。
- `Downloads` 的最近 20 条历史记录仅保存在内存中，退出启动器后清空。
- 搜索框的占位文案和清除提示随界面语言切换；阿拉伯语布局会镜像标题行与搜索框位置。

### 升级说明

直接替换旧版启动器即可，不需要迁移数据或修改配置：

1. 关闭正在运行的启动器和游戏。
2. 用新版本压缩包中的可执行文件替换旧文件。
3. 启动后原有的账户、实例、主题（默认 OpenCode）和数据目录设置都会保留。

如果之前通过 `--data-dir` 或 `MCLAUNCHER_DATA_DIR` 指定了数据目录，升级后继续使用相同参数即可。

### 安装

从下方 Assets 下载对应平台的压缩包：

- Windows：`mclauncher_0.2.1_windows_amd64.zip` / `mclauncher_0.2.1_windows_arm64.zip`
- Linux：`mclauncher_0.2.1_linux_amd64.tar.gz` / `mclauncher_0.2.1_linux_arm64.tar.gz`
- macOS：`mclauncher_0.2.1_darwin_amd64.tar.gz` / `mclauncher_0.2.1_darwin_arm64.tar.gz`

校验和见 `checksums.txt`。macOS 首次运行如被系统拦截：

```bash
xattr -d com.apple.quarantine ./mclauncher
```
