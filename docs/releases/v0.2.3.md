## 更新详情

v0.2.3 聚焦实例内容管理与创建流程：新增「资源与模组」窗口，可在材质包、光影和模组之间切换，从 Modrinth 搜索下载，也可以导入本地文件或 https 直链；新建实例表单中可以直接选择模组加载器；退出启动器时是否保留游戏改为可配置；Windows 下还可以自定义 Minecraft 游戏窗口标题。

### 资源与模组

- 在 `Instances` 按 `p` 打开「资源与模组」窗口，使用 `tab` / `←` `→` / `1` `2` `3` 在材质包、光影和模组之间切换。
- 支持从 Modrinth 搜索内容，并按实例的 Minecraft 版本与模组加载器过滤结果。
- 支持按 `i` 导入本地 `.zip` / `.jar`，按 `u` 粘贴任意 https 直链下载；从其他网站下载的内容同样可以安装。
- 材质包装入 `resourcepacks/`，并改写 `options.txt` 中的资源包开关；模组装入 `mods/`，使用 `.jar.disabled` 切换启用状态；光影装入 `shaderpacks/`，在游戏内选择。
- 下载内容按 SHA-512 校验；手动放进目录的文件也会被扫描并列出。
- 支持删除、重新扫描和打开对应内容目录。

### 实例创建与加载器

- 「新建实例」表单新增「Mod loader」行。
- 在表单中按 `enter` 选择 Fabric、Quilt、Forge、NeoForge 或 OptiFine，再选择加载器版本和安装用的 Java 运行时。
- 加载器安装完成后，新实例会自动指向对应的加载器版本，不再需要先回到 `Versions` 手动安装。

### 退出时保留游戏

- `Settings` 新增 `Keep game running` 开关，默认关闭。
- 关闭时，退出启动器会停止由它启动的 Minecraft 进程。
- 开启后，退出启动器不会停止游戏，适合希望继续在后台运行 Minecraft 的玩家。
- 正常退出、`q` / `ctrl+c` 和 Bubble Tea 异常退出路径都会遵循该设置。

### 游戏窗口标题

- `Settings` 新增 `Game window title`。
- 填写后会在游戏窗口出现时通过 Win32 API 修改标题；留空则保持 Minecraft 自带标题。
- 目前仅 Windows 支持；其他平台会保持原窗口标题。
- 启动器自己的终端窗口标题固定为 `MCLauncher TUI`。

### 项目维护

- 新增 GitHub Issue 与 Pull Request 模板，方便反馈问题和提交改动。
- 清理旧模组面板移除后遗留的文案与快捷键提示。
- README、预览页面和文档截图同步更新。

### 平台与兼容性

- Windows、Linux、macOS 的 `amd64` / `arm64` 构建目标保持不变。
- 旧版 `config.json` 继续兼容；新增的 `keep_game_running` 缺省为 `false`，升级后默认行为仍是退出启动器时停止游戏。
- 游戏窗口标题修改仅支持 Windows；其他平台不会受影响。
- 资源包兼容性最终由 Minecraft 的 `pack_format` 判断，启动器只按游戏版本过滤搜索结果；光影需要 Iris 或 OptiFine，模组需要对应的加载器。
- Modrinth 搜索和下载需要网络；本地文件导入与手动放入目录的方式可以离线使用。

### 升级说明

可以直接使用应用内更新，或下载新版本压缩包替换旧可执行文件；不需要迁移数据或修改配置。

1. 关闭正在运行的启动器和游戏。
2. 用新版本压缩包中的可执行文件替换旧文件，或在 `Settings → Launcher version` 中检查更新。
3. 启动后原有的账户、实例、资源与模组、Java 设置和数据目录都会保留。

如果之前通过 `--data-dir` 或 `MCLAUNCHER_DATA_DIR` 指定了数据目录，升级后继续使用相同参数即可。

### 安装

从下方 Assets 下载对应平台的压缩包：

- Windows：`mclauncher_0.2.3_windows_amd64.zip` / `mclauncher_0.2.3_windows_arm64.zip`
- Linux：`mclauncher_0.2.3_linux_amd64.tar.gz` / `mclauncher_0.2.3_linux_arm64.tar.gz`
- macOS：`mclauncher_0.2.3_darwin_amd64.tar.gz` / `mclauncher_0.2.3_darwin_arm64.tar.gz`

校验和见 `checksums.txt`。macOS 首次运行如被系统拦截：

```bash
xattr -d com.apple.quarantine ./mclauncher
```
